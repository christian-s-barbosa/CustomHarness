# Glossário de conceitos (canônico)

> Vocabulário controlado. Todo conceito usado nas observações e avaliações deve
> referenciar um **nome canônico** daqui. Sinônimos são mapeados para o canônico
> — evita fragmentar a matriz (`mutável` / `mutability` → `mutabilidade`).

## Índice de conceitos

|----------|-----------|-----------|----------------|

## Regras
- Todo conceito **novo** entra aqui primeiro (nome canônico + sinônimos).
- O **nome canônico** é o que aparece na matriz do `estado-atual.md`.
- Sinônimos servem só para o `sync` reconhecer e **não fragmentar**.
- **Pré-requisitos** alimentam a detecção de lacunas.
- A **definição** de cada conceito vive em `conceitos/<conceito>.md` (destilado).
